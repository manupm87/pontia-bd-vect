# Referencias

## Conjunto de datos

- Amazon Science, *Shopping Queries Dataset: A Large-Scale ESCI Benchmark for
  Improving Product Search*: <https://github.com/amazon-science/esci-data>
  (licencia Apache-2.0).
- Reddy et al. (2022), *Shopping Queries Dataset*, arXiv:2206.06588:
  <https://arxiv.org/abs/2206.06588>.

## Modelos de embeddings

- Wang et al. (2024), *Multilingual E5 Text Embeddings: A Technical Report*,
  arXiv:2402.05672: <https://arxiv.org/abs/2402.05672>. Modelo
  `intfloat/multilingual-e5-small`: <https://huggingface.co/intfloat/multilingual-e5-small>.
- Reimers y Gurevych (2019), *Sentence-BERT: Sentence Embeddings using Siamese
  BERT-Networks*, arXiv:1908.10084: <https://arxiv.org/abs/1908.10084>. Modelo
  `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`:
  <https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2>.

## Índice y base de datos

- Malkov y Yashunin (2018), *Efficient and robust approximate nearest neighbor

  <https://arxiv.org/abs/1603.09320>.
- Documentación de Qdrant: colecciones, HNSW y filtrado por payload:
  <https://qdrant.tech/documentation/concepts/>.
- Cliente Python de Qdrant: <https://github.com/qdrant/qdrant-client>.

## Métricas y baseline léxico

  Beyond*. Foundations and Trends in Information Retrieval 3(4).
